# DC-Circuit-Analysis
Analysis and simulation of DC circuits using basic electrical laws

This project includes the analysis and simulation of DC circuits using fundamental electrical engineering principles.

## 🔧 Concepts Covered
- Ohm’s Law
- Kirchhoff’s Voltage Law (KVL)
- Kirchhoff’s Current Law (KCL)

## 🛠️ Tools Used
- Multisim / Proteus
- MATLAB (basic)

## 📂 Contents
- Circuit diagrams
- Simulation results
- Calculations and lab work

## 📌 Description
This repository contains my academic work related to DC circuit analysis, including solved problems, simulations, and practical lab experiments.
